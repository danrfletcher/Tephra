# Tephra

A federated graph and link engine for plain-text notes, code folders and documents, written in Rust: a daemon (`tephrad`) and a CLI (`tephractl`). Block links (`[[path#^id]]`), search by name, heading, block and full text, link refactoring on disk, and a launchd agent for macOS are all on `main`.
